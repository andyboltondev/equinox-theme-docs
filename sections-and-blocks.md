# Sections & blocks

## Content sections

Add these from **Add section** on any template that allows sections.

| Section | Notes |
|---|---|
| **Hero** | Full-width image or video hero. Separate desktop and mobile images with independent focal points, overlay opacity, optional translucent content panel, eyebrow / heading / body / two buttons, adjustable height. Leave the image blank to use the preset's lifestyle image. |
| **Rich text** | Eyebrow, heading, body and buttons as individual blocks; alignment, max width, and surface. |
| **Image with text** | Image beside text, image left or right, eyebrow / heading / body / button. |
| **Multicolumn** | 1–6 columns, each with an icon or image, heading, text and link. |
| **Collection list** | Manually chosen collections in an adaptive card grid. |
| **Featured collection** | Products from one collection, adjustable count and density, "view all" link. |
| **Product recommendations** | Shopify's related-products output on the product page. |
| **Newsletter** | Email capture wired to Shopify customer marketing. |
| **Contact form** | Standard Shopify contact form with configurable fields. |
| **Multicolumn / Rich text / Image with text** | all expose a **Background** (surface) setting so you can alternate section grounds consistently in light and dark. |
| **Apps** | A section that only holds an app block. |
| **Flexible blocks** | A general-purpose section that accepts **theme blocks and app blocks**, for building custom layouts and placing app content anywhere. |
| **Custom Liquid** | Raw Liquid / HTML for advanced cases. |
| **Announcement bar** | One or more rotating announcements above the header. |
| **Theme demo grid** | The "compare the presets" grid used on this theme's own demo page (optional). |

## Header

- Main menu (supports a mega-menu layout and a mobile drawer)
- Sticky header toggle
- Show / hide search and account
- **Cart icon action**: go to cart page, or open the cart drawer

## Footer

- Menu blocks and text blocks
- Payment icons, social links (from **Theme settings → Social media**),
  locale / currency selectors where enabled in Shopify Markets

## Collection pages

**Collection products** section:

- Show / hide collection description and image
- **Enable filtering** and **Enable sorting** (uses Shopify's native
  Search & Discovery filters)
- Products per page
- **Product size** (grid density) and a separate **small-screen layout**

## Templates covered

Home, Product, Collection, Collection list, Search, Blog, Article, Page,
Cart, 404, Password, and the full customer account set (login, register,
account, addresses, order, activate, reset password).
