# Getting started

## 1. Add the theme

If you bought Equinox Trail from the **Shopify Theme Store**, it is already in your
theme library. Open **Online Store → Themes** and you will see it under
"Theme library". Nothing to download or upload. Use **Customize** to set it up
against a preview, then **Publish** when you are ready. Future updates appear
in the same place and are applied in a click.

If you received Equinox Trail as a `.zip` (a trial copy, or a non–Theme-Store
purchase): **Online Store → Themes → Add theme → Upload zip file**, then
Customize / Publish as above.

## 2. Choose a preset

Equinox Trail ships with five presets. Each one sets the light and dark colour
palettes, all four font roles, the type scale, spacing, and card and button
shape together, and comes with a matching demo homepage.

- If you are adding the theme fresh, pick the preset that is closest to your
  brand from the style options Shopify shows you.
- To change preset later, use the theme library **style / preset selector**
  for Equinox Trail (the exact location depends on your Shopify version; look for
  "Change theme style" or the preset thumbnails next to **Customize**).

Changing preset replaces the theme-wide design settings. It does **not** touch
your section content, menus, logo, or product data. See
[Presets](presets.md) for what each one is for.

## 3. Brand basics

In the editor, open **Theme settings**:

- **Brand**: logo, logo width, favicon, and a default social sharing image.
- **Light colour palette** / **Dark colour palette**: set these to your brand
  colours. Each mode has ten roles (background, surface, alternative surface,
  text, muted text, borders, primary action + text-on-primary, secondary
  action + text-on-secondary). Keep each "text on…" colour readable against
  the colour it sits on.
- **Typography**: choose fonts for body, display/H1, H2–H6, and UI. System
  fonts load instantly; Google and web-safe fonts are served from Shopify's CDN.

## 4. Navigation

- **Header** section: pick your main menu. The header supports a mega-menu
  layout and a mobile drawer.
- **Footer** section: pick your footer menus and add footer content blocks.

## 5. Homepage and content

The demo homepage is built from standard sections (hero, rich text, collection
list, featured collection, image with text, multicolumn, newsletter). Replace
the demo text and images with your own, remove sections you do not need, and
add sections from the **Add section** menu.

## 6. Go live

When the storefront looks right in both light and dark mode (use the mode
switcher in the header to check), publish the theme from **Online Store →
Themes**.
