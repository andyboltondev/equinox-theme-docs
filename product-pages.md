# Product pages

## Gallery (section settings)

On the **Product information** section:

- **Media aspect ratio** and **media fit** (contain / cover)
- **Show thumbnails** and **thumbnail position**
- **Show arrows**
- **Loop videos**
- **Sticky product info**: the buy column stays in view while the gallery
  scrolls on desktop

Variant-specific images are supported: when the theme has variant images it
moves the gallery to the matching image as the shopper changes variant.

## Blocks

Arrange, add, or remove these on the **Product information** section:

| Block | Notes |
|---|---|
| **Vendor** | |
| **Title** | |
| **Price** | Shows sale, unit, and "from" pricing; taxes/shipping note |
| **Variant picker** | Buttons or dropdowns; reflects availability |
| **Quantity** | |
| **Buy buttons** | Add to cart + optional dynamic checkout button |
| **Description** | The product description |
| **Collapsible row** | An accordion row: free text or a linked Page. Add several for delivery, care, sizing, etc. |
| **Share** | Native device share plus Facebook, X, Pinterest, LinkedIn, WhatsApp, email, and copy-link, each toggleable; centred or left aligned |
| **Map** | An embedded Google map with address and directions link, for made-to-order or in-store products |
| **Custom Liquid** | |
| **App block** | Any product app that supports theme app blocks |

## Metafield accordions

Use the **Flexible blocks** section on the product template to add a
**Metafield accordion** theme block. It builds collapsible rows directly from
your product metafields, so specs and details stay in structured data rather
than being retyped into the description.

## Related products

Add the **Product recommendations** section below the product information to
show Shopify's related-products output.
